# Design and Analysis of Algorithms (DAA) Lab

Welcome to the **Design and Analysis of Algorithms** laboratory repository. This project serves as a centralized hub for tracking, implementing, and analyzing core algorithms. 

The primary focus of these labs is to bridge the gap between theoretical algorithmic concepts and practical execution, with a strong emphasis on **time and space complexity benchmarking**.

### 🚀 Covered Paradigms
*   **Divide and Conquer:** Binary Search, Merge Sort, Quick Sort
*   **Greedy Method:** Knapsack Problem, Dijkstra's, Minimum Spanning Trees (Kruskal's/Prim's)
*   **Dynamic Programming:** 0/1 Knapsack, Longest Common Subsequence (LCS), Matrix Chain Multiplication
*   **Backtracking & Branch and Bound:** N-Queens Problem, Travelling Salesperson Problem
*   **Graph & String Matching:** BFS/DFS, KMP, Rabin-Karp

### 🧪 Contribution Guideline for Labs
1. **Fork** this repository.
2. Create a clean folder matching the lab format (e.g., `Lab-04_QuickSort/`).
3. Include your source code and a short `README.md` or comment block highlighting the **Time Complexity (Best, Average, Worst case)** and empirical execution graphs if required.
4. Submit a **Pull Request** with a descriptive commit message.
